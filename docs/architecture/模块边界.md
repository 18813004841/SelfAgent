# SelfAgent-模块边界

## 1. 运行单元

| 模块 | 入口/边界 | 允许的依赖方向 |
| --- | --- | --- |
| 工作台 | `workbench/machine-dashboard-server/src/server.py` | 调用 View、存储、ProcessManager 和外部启动器 |
| 机器控制 | `Tools/machine-control/server`、`client`、`shared` | 中央服务与 Worker 通过既定协议通信 |
| 代码检查 | `Tools/code-review-agent/code_review/cli.py` | 读取目标工程增量、规则和模型服务，不依赖 OpenAiAgent 业务 |
| 智能体 | `AiAgent/AiProject/Codes/Agents/OpenAiAgent` | 自主管理 OAuth、CLI 和本地网关 |
| 技能 | `skills/<name>/SKILL.md` | 提供开发流程约束，不作为运行时业务依赖 |

## 2. 稳定入口和默认值

| 名称 | 当前值或位置 | 用途 |
| --- | --- | --- |
| 工作台 | `MACHINE_DASHBOARD_HOST`、`MACHINE_DASHBOARD_PORT=18888` | 本地 HTTP 服务 |
| 控制中心 | `MACHINE_CONTROL_PORT=18765` | 机器控制服务 |
| 智能体网关 | `CODEX_GATEWAY_PORT=8765` | 本地 `/v1` 模型网关 |
| 本地 Codex | `CODEX_APP_SERVER_PORT=4500` | 工作台启动的本地服务 |
| 工作台会话 | `LOCAL_WORKBENCH_START_TIMESTAMP` | 日志会话标识 |

实际默认值以目标代码为准；改变端口、路径或环境变量时必须同步文档和调用方。

## 3. 接口契约

- 工作台页面：`web/pages` + `web/assets/js/pages` 通过 HTTP JSON 调用 `src/view`；成功响应通常包含 `ok: true`，失败响应包含 `ok: false` 和 `error`。
- 工作台进程：业务接口请求稳定服务名；ProcessManager 调用对应启动器处理命令、环境、PID 和状态。
- 插件工具：使用 `tool_id + args`，本地进程入口接收 JSON 参数，退出码 0 表示成功，标准输出作为结果。
- 代码检查：`python -m code_review.cli` 由配置驱动，检查通过才更新成功基线。
- 智能体：对外提供本地 `/v1` 接口；工作台不读取或返回令牌。

## 4. 归属判断

1. 页面、设置、调度、进程状态和工作台接口归 `workbench/machine-dashboard-server`。
2. 中央控制、Worker、机器控制协议归 `Tools/machine-control`。
3. Unity 增量检查、规则加载和报告归 `Tools/code-review-agent`。
4. OAuth、模型网关和 Agent 工具调用归 OpenAiAgent。
5. 可复用开发流程归 `skills`；技能文件不应写入项目运行时路径。

不确定归属时先记录为待确认，查清入口和调用方后再移动代码。
