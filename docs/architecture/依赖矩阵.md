# SelfAgent-依赖矩阵

| 调用方 | 被调用方 | 方式 | 当前状态 | 治理约束 |
| --- | --- | --- | --- | --- |
| 浏览器页面 | 工作台 View/legacy API | HTTP JSON | 已存在 | 页面字段、路由、错误结构需同步 |
| 工作台 server | View、存储、ProcessManager | Python import/调用 | 已存在 | 工作台负责组装，不把外部业务复制进来 |
| 工作台 Launchers | 调度器、机器控制、Worker、Agent、Local Codex | 子进程 | 已存在 | 稳定服务名、PID、端口、停止行为需登记 |
| 工作台调度器 | 代码检查工具 | Python import/子进程，需按实际任务核对 | 部分确认 | 不能把模型服务或目标工程状态写入工作台核心契约 |
| 代码检查工具 | Git 目标工程 | Git/文件 | 已存在 | 成功基线仅在检查通过后更新 |
| 代码检查工具 | 模型服务 | HTTP | 已存在 | 失败不能伪装成通过，不执行模型返回命令 |
| Machine Control Worker | 中央服务 | HTTP JSON | 已存在 | 认证、心跳、任务状态和版本兼容需明确 |
| Machine Control MCP | 中央服务 | HTTP 客户端/MCP stdio | 已存在 | MCP 层只做协议适配，不复制控制业务 |
| OpenAI Agent 网关 | Codex 上游 | HTTP/OAuth | 已存在 | 令牌留在 Agent 边界，不进入工作台日志或响应 |
| 技能 | 开发任务 | 文档加载 | 已存在 | 技能提供流程约束，不成为运行时 import |

## 当前待审计耦合

- 工作台代码中 `sys.path` 修改和根路径推导需要逐项判断是否可替换为包入口。
- `Tools/code-review-agent` 对 OpenAI Agent 本地配置的回退读取需要确定是否保留。
- 机器控制 `client`、`packages/central-client` 和工作台启动器之间存在源码/打包副本，需要确认发布源。
- `Tools/local_codex` 的目录职责和工作台 Local Codex 进程边界需要补充证据。
