# 入口清单

本清单只记录当前已定位的运行入口。新增入口时同步补充调用方、配置和验证方式。

| 入口 | 类型 | 调用方 | 当前配置 |
| --- | --- | --- | --- |
| `workbench/machine-dashboard-server/src/server.py` | HTTP 服务 | 工作台启动脚本和浏览器 | `MACHINE_DASHBOARD_HOST`、`MACHINE_DASHBOARD_PORT=18888` |
| `Tools/machine-control/server/control_center/server.py` | HTTP 服务 | 工作台中央服务启动器 | `MACHINE_CONTROL_PORT=18765` |
| `Tools/code-review-agent/code_review/cli.py` | CLI | 调度器和人工检查命令 | 配置文件、Git 仓库和模型服务 |
| `AiAgent/AiProject/Codes/Agents/OpenAiAgent/codex_agent/openai_gateway.py` | HTTP 网关 | 工作台智能体启动器 | `CODEX_GATEWAY_PORT=8765` |
| `AiAgent/AiProject/Codes/Agents/OpenAiAgent/codex_agent/cli.py` | CLI | 人工登录和对话 | `CODEX_TOKEN_PATH` 和 OAuth 环境变量 |
| `Tools/machine-control/server/control_mcp/server.py` | MCP 服务 | 机器控制 MCP 客户端 | MCP 包和命令行参数 |
