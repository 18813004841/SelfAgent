# 环境与依赖治理

## 选择

三个运行单元采用项目独立环境：工作台、machine-control、AiAgent 分开安装和启动。原因是 machine-control 只需要 MCP/标准库，AiAgent 有 OAuth、可选 LangChain，工作台依赖 Web/调度组件；共享环境会把可选依赖和版本冲突引入所有服务。

启动器必须使用确定解释器：

- 工作台：`workbench/machine-dashboard-server/.venv/Scripts/python.exe`（没有时由启动脚本显式配置），测试使用隔离 `LOCALAPPDATA`。
- machine-control：`MACHINE_CONTROL_PYTHON` > `Tools/machine-control/.venv/Scripts/python.exe` > PATH `python`；运行中央服务时同时设置 `PYTHONPATH=server;shared`。
- AiAgent：`AiAgent/AiProject/Codes/Agents/OpenAiAgent/.venv/Scripts/python.exe` 或其 Conda 环境；安装工程自身 `pyproject.toml`，使用 `uv.lock` 锁定可复现版本。

## 依赖责任

| 项目 | 运行依赖 | 开发/测试 | 锁定策略 |
|---|---|---|---|
| 工作台 | `workbench/machine-dashboard-server/requirements.txt`（`psutil` 和打包报错分析使用的 `langgraph`） | `requirements-dev.txt` | 工作台源码 import 审计脚本；根 `requirements.txt` 保留为历史/其他业务兼容清单 |
| machine-control | `Tools/machine-control/pyproject.toml`，MCP 为可选项 | `pip install -e ".[mcp]"` | `uv.lock`；使用 `uv sync --locked` |
| AiAgent | `pyproject.toml` 的 httpx、dotenv | `.[test]`；LangChain 为 `.[langchain]` | `uv.lock`；Conda 仅作为 Python 3.11 引导环境 |

## 命令

```powershell
# machine-control
$env:MACHINE_CONTROL_PYTHON="Tools/machine-control/.venv/Scripts/python.exe"
& $env:MACHINE_CONTROL_PYTHON -m pip install -e ".\Tools\machine-control[mcp]"

# AiAgent
cd AiAgent/AiProject/Codes/Agents/OpenAiAgent
uv sync --extra test
uv run python -m codex_agent.cli --help

# 工作台（使用已有依赖环境）
$env:PYTHONPATH="workbench/machine-dashboard-server/src"
python scripts/check_architecture.py
python scripts/validate_workbench_storage.py
```

安装和升级必须在目标项目目录执行；虚拟环境、缓存、日志、数据库和凭据不提交。网络不可用时只执行入口帮助和语法检查，不声称依赖安装成功。

## 工作台配置优先级

工作台配置采用：内置默认值 < 用户配置文件 `%LOCALAPPDATA%/LocalWorkbench/config/local_setting.json` < 环境变量。支持 `WORKBENCH_LOG_LEVEL`、`WORKBENCH_DEBUG_LOG`、`WORKBENCH_OUTPUT_DIR` 和 `WORKBENCH_LOG_PATH`。目录会自动创建并通过临时文件验证可写性；失败会以配置错误中止启动。

三项目入口验证命令：`python scripts/validate_project_entrypoints.py`。它使用绝对工程路径和显式 `PYTHONPATH`，验证 AiAgent CLI、machine-control 中央服务帮助和工作台服务语法；依赖安装仍需在具备构建工具的干净环境中执行。

环境初始化命令：`python scripts/bootstrap_projects.py --project all`。三个项目分别使用各自目录下的 `.venv`，启动器不依赖终端激活状态；`--upgrade` 才会升级 pip。脚本不会覆盖已有环境，安装失败会停止并保留现场。当前 machine-control 与 AiAgent 使用各自 `pyproject.toml`，工作台仍使用仓库现有 `requirements.txt`，其依赖拆分列为后续技术债。
