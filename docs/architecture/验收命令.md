# SelfAgent 本地验收命令

```powershell
python scripts/check_architecture.py
python scripts/check_architecture.py --tracked-artifacts
python scripts/validate_workbench_storage.py
```

`--tracked-artifacts` 是交付前严格检查，会报告历史运行产物；取消跟踪时只使用 `git rm --cached`，保留本地文件。

工作台页面和服务使用隔离 `LOCALAPPDATA`、`MACHINE_DASHBOARD_PORT` 启动；machine-control 使用独立 `.venv` 或 `MACHINE_CONTROL_PYTHON`，并为 server/shared 设置模块路径。
